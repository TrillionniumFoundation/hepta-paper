# Gap closure execution — 2026-09-09

This branch is the evidence-first convergence branch for the current Rust replacement candidate.

## Rules

1. Repository-local defects are fixed and requalified on one exact immutable head.
2. A gap closes only when its canonical schema and verifier accept retained evidence bound to the exact repository, base, head, tree, tested merge, workflow identities, run attempts, jobs, steps and artifacts.
3. External facts are never self-asserted by source, fixtures, model output, administrator prose or boolean flags.
4. Target-host, credential-owner, key-owner, KMS/HSM, WORM, release, portal, submission and private-archive facts remain fail-closed until independently issued evidence is ingested and reviewed.
5. Node authority is retired only after parity, migration, shadow/canary, rollback and single-writer transfer evidence are accepted.

This document grants no production authority.
