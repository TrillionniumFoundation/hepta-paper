## Source implemented

### P0 corrections

- `CODEX_HOME` root identity now excludes volatile directory size, link count,
  mtime and ctime while retaining canonical path, device, inode, mode, UID/GID;
- config and known credential metadata remain exact identities;
- invocation policy separates execution, schema and output owners;
- production schema requires a distinct authority UID and read-only group path;
- schema parent directory identity is bound before and after execution;
- schema and output control files are forbidden inside the mutable workspace;
- same-owner schema mode is explicitly test-only and non-production eligible.

### Admission

- `HEPTACX1` bounded request frame;
- Linux `SO_PEERCRED` inspection;
- exact UID/GID allowlist;
- exact broker role, sandbox and qualified-runtime-identity binding;
- short-lived peer-bound Ed25519 capability;
- strict verification and weak-key rejection;
- request fields, role, model, sandbox, hashes, generation, budget and deadline
  included in domain-separated signing bytes;
- authenticated request fields are private outside the broker crate.

### Durable state

- private broker-owned SQLite database;
- bundled SQLite, `NOFOLLOW`, WAL, `synchronous=FULL`, foreign keys and bounded
  max page count;
- atomic operation/idempotency/nonce reservation with exact consumed timestamp
  and deferred circular foreign-key closure;
- expiration recheck before durable reservation;
- exact duplicate lookup without a second spawn;
- append-only transition table and immutable nonce table;
- compare-and-swap state projection;
- provider-start and prepared-receipt projections;
- application/user/schema identity, exact STRICT schema manifest and closed
  metadata-manifest validation on open;
- transaction rollback injection after operation/nonce/transition/projection
  writes, followed by close/reopen verification;
- crash-stable private initialization marker with exact empty/stamped recovery
  rules;
- foreign/unmarked-empty database, malformed marker, extra-schema-object and
  extra-metadata rejection;
- reopen/reconstruction tests.
