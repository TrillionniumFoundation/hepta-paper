# Rust G0 Qualification Subject V3

The canonical executable G0 identity is defined by:

- `docs/qualification/QUALIFICATION_SUBJECT_V3_RUNTIME.md`;
- `docs/rust/tools/qualification_subject_v3.py`;
- `.github/workflows/rust-qualification-subject-v3.yml`;
- `.github/workflows/rust-qualification-subject-v3-revalidation.yml`.

This marker deliberately lives under `rust/` so every Rust source, installed
principal, supply-chain, qualification, and exact-head producer executes for the
G0 candidate. It grants no runtime, provider, writer, release, submission, or
external authority.
