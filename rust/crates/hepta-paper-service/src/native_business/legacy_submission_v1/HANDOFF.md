Original source blobs are retained as test-only reference modules, including a literal artifact/metadata type excerpt from the original types blob. Inputs are converted field-by-field into those independently declared reference types, so serialization changes cannot affect both sides unnoticed. Differential tests invoke their actual functions over normal, ordering, limit, invalid-hash and duplicate inputs, then compare entire output bytes/evidence/errors with the new dispatched jobs. Namespaced types separate the incompatible old protocols; the job discriminants are deliberately new explicit names, not an ambiguous alias for old `submission_package`.

All outputs are prepared data only. Public hash/length claims do not prove source artifacts, scientific validity, current state, independent permission or external submission. No portal/provider/credential/process execution was added. The implementation identity now includes the new production modules; it changes even though the original job output does not. Adding public enum variants is a source-compatibility consideration for exhaustive downstream matches.
